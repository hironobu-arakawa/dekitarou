初回の現場訪問で技術の話は半分でいい。残り半分は、**この現場がどういうルールで動いているかを知り、そのルールを尊重できる人間だと示す**ことに使う。現場は、設備の知識より先にそこを見ている。

## 訪問の前に(アポの段階で確認する)

- [ ] 訪問時の服装・保護具の指定(安全靴・ヘルメット・保護メガネ。貸与か持参か)
- [ ] 入場手続き(受付・入構教育・誓約書の有無。所要時間も聞く)
- [ ] 写真撮影の可否と手続き(**現地で聞くのでは遅い**。撮れないなら記録手段を変える)
- [ ] 当日同席してもらう人(現場の管理者に加え、可能なら保全担当者。設備の話は保全としかできない)
- [ ] 訪問の目的の共有(「調査であり、この日に見積は出ない」ことを先に言っておく)

## 持ち物

- [ ] 筆記具と方眼ノート(スマホのメモは、現場では失礼にあたる場面がある)
- [ ] メジャー・懐中電灯
- [ ] スマホ(電波確認用。設置予定場所での電波状況は必ずその場で実測する)
- [ ] 名刺と、あれば過去の構成例など話の種になる紙(製品カタログではなく)

## 現場で見るもの

技術要素は案件ごとの現地調査項目([各案件カード](/cases/)参照)に従う。ここでは案件を問わず共通のものだけ挙げる。

- [ ] 電源(コンセントの位置と系統。「借りていい電源」がどれかは必ず聞く)
- [ ] 電波(設置予定場所での実測。金属壁・地下・冷蔵庫内は特に)
- [ ] ネットワーク(現場のWi-Fi・有線の有無と、**つないでよいかを決められる人が誰か**)
- [ ] 環境(粉塵・油・水・温度・振動。機器の保護等級に直結する)
- [ ] 動線(自分が作業する場所は、現場の人や物の流れを妨げないか)

## 現場で聞くもの — 5つの管理点

現場は**安全・品質・生産・原価・環境**の軸で管理されている。訪問の会話をこの5軸で一巡させると、聞き漏れが構造的に減る。

- [ ] **安全** — この現場で守るべき安全ルールは何か。立入禁止・活線・高所。自分の作業がどれに触れるか
- [ ] **品質** — 今回のデータ・仕組みは品質記録や監査に関わるか。関わるなら品質部門の窓口は誰か
- [ ] **生産** — 調査・設置のために現場に入れるのはいつか。生産を止める必要はあるか、あるなら誰が調整するか
- [ ] **原価** — この案件の費用は誰の予算か。月額費用を払い続ける前提はあるか
- [ ] **環境** — 数字が省エネ・環境報告に使われる可能性はあるか。廃棄物(電池・機器)のルールは何か

## 帰る前に確認するもの

- [ ] 次のアクションと期日(「見積は調査結果を整理して◯日までに」と自分から言う)
- [ ] 連絡経路(窓口は誰か。現場に直接連絡してよいのか、必ず窓口経由か)
- [ ] 今日見られなかったもの・会えなかった人(次回に回すものを明示しておく)

## やってはいけないこと

- 勝手に設備・盤・スイッチに触る(**見るだけでも、まず断る**。「触っていいですか」は現場で最も安い保険)
- 勝手に写真を撮る
- 現場の人の作業を呼び止めて長く話す(話を聞くなら管理者経由で時間をもらう)
- その場で金額を口にする(「だいたいいくら?」には幅で答え、確定は調査後と言う)
- できるかどうか分からないことを「できます」と言う(現場は約束を覚えている)
